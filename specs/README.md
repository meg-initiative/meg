# Legacy MEG Specifications

This directory contains historical MEG v4.6.2 materials, including the earlier Bronze, Silver and Gold compliance structure.

These files are retained for:

- version traceability;
- historical research;
- comparison with the current framework;
- preservation of the development history of MEG.

They are not the current MEG standard.

The current authoritative specifications are MEG1 v5.0 and MEG2, available in:

- ../meg1-meg2/
- https://meg-initiative.org/library/

The legacy `meg-sdk` implementation is archived and is not compatible with MEG1 v5.0 or MEG2.
